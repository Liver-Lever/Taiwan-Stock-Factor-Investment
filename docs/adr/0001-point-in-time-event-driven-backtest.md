# ADR-0001：採用 point-in-time 事件式月調倉架構

- 狀態：已接受
- 日期：2026-11-07

## 背景

策略同時使用月底電子類股指數訊號、0050 歷史成分股與個股因子。若直接用月底收盤價成交、用現在的 0050 成分股回推，或按事後整理的生效日取得尚未公布的名單，績效都會含有前視偏誤。

## 決策

採用事件式月調倉：月底最後交易日收盤後形成訊號，下一交易日以調整後開盤價建立部位。每個成分股快照同時保存 `available_date` 與 `effective_date`；策略只可使用兩者均不晚於訊號日的最新快照。個股報酬使用調整後價格，換手率依前期漂移後權重計算，再扣除可設定的單邊交易成本。

因子 baseline 與產業狀態訊號分離。動能、低波動屬於個股橫斷面因子；電子指數 MA20 屬於市場狀態變數，不把兩者混稱為同一種因子。

## 替代方案

1. 同日收盤成交：程式較簡單，但月底收盤訊號在該收盤前不可知，因此拒絕。
2. 使用最新 0050 成分股回測全期間：資料容易取得，但有存活者偏誤，因此拒絕。
3. 使用電子期貨連續契約：需處理換月與轉倉跳空，MVP 優先使用電子類股現貨指數。
4. 直接把所有策略改成低波動權重：無法隔離「產業減碼」與「因子選股」的效果，因此保留獨立 baseline。

## 後果

優點是訊號、資訊可得日與成交時點都能稽核，並能公平比較原 0050、固定減碼、動態減碼及前 N 等權策略。代價是正式回測必須取得歷史成分股快照、公布日與調整後開盤價；缺資料時系統會停止，而不是自行回填。
