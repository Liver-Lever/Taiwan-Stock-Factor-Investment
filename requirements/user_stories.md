# 第 2 週 MVP 使用者故事與接受標準

## US-001 可稽核的因子計算

身為研究者，我希望只用訊號日以前的價格計算動能與低波動因子，以免未來資料洩漏到選股結果。

接受標準：

1. 動能因子使用訊號日以前含當日的 126 個交易日報酬。
2. 低波動因子使用訊號日以前含當日的 60 個日報酬標準差。
3. 動能愈高分數愈高，波動率愈低分數愈高。
4. 歷史不足或價格缺漏的股票不進入可選名單。

## US-002 可重現的前 N 名 baseline

身為作業評分者，我希望能重現規則式前 N 名等權策略，以判斷智慧方法是否真的優於簡單規則。

接受標準：

1. 合成分數為動能分數與低波動分數的等權平均。
2. 每次調倉只持有合成分數最高的 N 檔股票。
3. 入選股票的目標權重相等且總和為 100%。
4. N、兩個回看期與交易成本可由設定檔修改。

## US-003 電子產業強弱動態調權

身為策略設計者，我希望在電子類股指數轉弱時降低電子股曝險，在轉強時恢復 0050 原權重。

接受標準：

1. 每月最後交易日收盤後比較電子類股現貨指數與 MA20。
2. 收盤低於 MA20 的 98% 時進入弱勢，電子股原權重減少 25%。
3. 收盤高於 MA20 的 102% 時恢復強勢，介於兩者之間則延續前一期狀態。
4. 減碼資金依原權重比例分配至非電子股，總權重保持 100%。
5. 新權重只能在下一個交易日生效。

## US-004 無前視偏誤的成本回測

身為風險審查者，我希望回測使用當時已公布的 0050 成分股資料並扣除換手成本，以免高估策略表現。

接受標準：

1. 訊號日只能取得 `available_date` 與 `effective_date` 均不晚於訊號日的最新快照。
2. 樣本內期間固定為 2015/01 至 2022/12，樣本外資料不得參與因子或參數決定。
3. 每次調倉依漂移後權重計算單邊換手率並扣除設定的基點成本。
4. 輸出原 0050、固定減碼、動態減碼、前 N 等權及臺灣加權報酬指數的月報酬與績效指標。
5. 正式模式遇到模擬資料或非 point-in-time 資料清單時必須停止。

## US-005 可重現的交件與報告

身為作業評分者，我希望用單一指令重跑資料驗證、測試與回測，並在簡報中辨識假設與限制。

接受標準：

1. README 提供一行指令完成環境建立、測試與回測。
2. 自動測試失敗時，重現流程立即停止且不覆蓋成功結果。
3. 回測報告包含因子、模型、績效、成本、換手率與心得。
4. 模擬資料與真實資料結果使用不同輸出目錄，報告不得混用。
5. 繳交資料夾包含 spec、pipeline、tests、ai_log 與 README 導覽。
